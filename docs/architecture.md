# 项目架构

本项目围绕闲鱼数字商品上架准备与本地运营，分为资料整理、真实案例素材与文案、上游闲鱼后台本地运行三部分。它提供本地工具和可复核的示例，不代表已连接闲鱼账号，也不代表商品已经发布或完成交付。

## 1. 商品资料整理

商品资料层负责把来源文件整理成可供人工审核和后续制作的清晰输入，例如商品名称、内容说明、交付方式、适用对象、价格信息和需要用户确认的事项。发布前应由运营者核对授权、事实准确性、平台规则与最终文案。

历史流程源码保存在 `workflows/legacy/`，包括资料盘点、分类计划、上传、目录核对与抽样回读。输出应保持来源可追溯；未确认的信息应标记待核对，不能把推测写成商品承诺。公开仓库仅保留通用说明、模板和经确认可公开的样例，不放客户资料、账户数据或私有文件。

## 2. 真实商品案例：九图与文案

案例部分展示两组完整商品展示素材及配套文案，包含主图与按浏览顺序编排的详情图。九张图应共同说明商品内容、核心价值、交付方式和购买前须知，保持视觉风格与信息一致。文案应以真实商品能力和可兑现的交付内容为依据。

案例素材须由项目维护者确认公开权利后再纳入。公开版本只收录选定的最终导出图和相应文案；不收录完整素材源库、参考图、未选方案、编辑过程文件或含个人信息的截图。素材授权或来源应在案例说明中标记清楚。

## 3. 闲鱼后台：本地运行的上游项目

后台功能基于第三方项目 [GuDong2003/xianyu-auto-reply-fix](https://github.com/GuDong2003/xianyu-auto-reply-fix)，采用 AGPL-3.0。为保留来源、便于复现并缩小本项目的第三方代码副本，本仓库不复制整份上游代码，而通过固定版本检出和独立补丁接入：

- `scripts/bootstrap_upstream.sh` 固定检出提交 `e8fe7ba4239614fe64d194cf3bed8a3aa16d5ab6`。
- `patches/manual-verification-status-fix.patch` 保存本项目维护的人工验证状态修正。

后台上游采用 FastAPI/Uvicorn、SQLite 与 Playwright/DrissionPage，提供本地 Web 管理界面及闲鱼账号自动化相关能力。上游代码、依赖和许可证仍归其原作者及相应许可约束；使用者应阅读上游许可证和平台规则。接入或更新时应检查固定提交、补丁是否可应用、依赖是否兼容，并保留上游归属与变更说明。

本仓库的运行适配脚本位于 `runtime/`，用于启动上游服务、管理本地服务和配置浏览器运行环境。适配层与第三方上游分开维护，避免把本机环境调整伪装成上游功能。

## 数据与边界

本项目仓库用于公开代码、文档和经过授权的示例素材。运行数据库、会话、Cookie、账号信息、浏览器配置文件、日志、备份、私有链接及完整素材源库属于本地运行或私有资料，不进入版本控制。公开文档中的历史记录只说明当时观察到的结果，不能作为当前运行状态或线上发布成功的证明。
